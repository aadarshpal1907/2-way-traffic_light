# 2-way-traffic_light
This project involves the design of a finite state machine (FSM) to control traffic lights at a two-way road intersection. The controller operates based on a clock (clk) and reset (reset) signal and produces two 3-bit outputs, light_A and light_B, which represent the Red, Green, and Yellow lights for Road A and Road B respectively. The FSM cycles through four main states to manage traffic flow safely and efficiently: Road A Green and Road B Red, Road A Yellow and Road B Red, Road A Red and Road B Green, and Road A Red and Road B Yellow. Transitions between these states are governed by internal counters that simulate timing durations—typically, Green for 10 seconds and Yellow for 3 seconds. The output format (e.g., light_A = 010) indicates which light is active using bit positions assigned to Red, Green, and Yellow. The entire system is designed to operate in a continuous loop, ensuring an orderly and predictable pattern of light changes, preventing collisions and managing traffic effectively. The design is simple, modular, and well-suited for implementation on FPGA or ASIC platforms, and it can be verified using digital simulation tools. The FSM approach also allows easy modification for more complex traffic systems.
